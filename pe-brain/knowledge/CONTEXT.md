# knowledge: shared engineering knowledge (L3)

Canonical home for anything true across projects. Route to one domain, load one or two notes, cite their paths. `INDEX.md` lists every note with authority and owner (generated).

## Domains

| Domain | Router | Covers |
|---|---|---|
| network | `network/CONTEXT.md` | Segmentation, IP planning, firewall flows, NTP, Windows RPC ports |
| opc | `opc/CONTEXT.md` | OPC UA, OPC DA over DCOM, bridges, run signals |
| sizing | `sizing/CONTEXT.md` | Server, storage and bandwidth sizing method and component profiles |
| products | `products/versions.md` | Product and tag versions, which versions are current |

## Reading rule

Check each note's `authority:` before using it (ladder in `../_system/schema.md`). Quote `unverified` content only with a flag to the PE.

Follow `../CONTRIBUTING.md`. Copy `../_templates/knowledge-note.md`. Never paste client evidence here.
