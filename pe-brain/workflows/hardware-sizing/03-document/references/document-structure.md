# Sizing specification structure

Proposed structure. Replace with the Stone Three template when supplied (`[TBC: Danie]`).

1. **Purpose and scope.** Site, products and versions.
2. **Minimum server specification.** CPU cores, RAM, storage, network interface, from the totals with headroom.
3. **Network load.** Total stream rate and where it crosses zones (link to the network requirements if they exist).
4. **Storage and retention.** Daily volume, retention days, total.
5. **Basis.** Per-component table from the result, policy values and sources, rounding rule.
6. **Open items.** Every gap with owner.
7. **Revision table.**
