# 02-calculate: run the sizing arithmetic

One job: compute totals from the input sheet with the deterministic tool and explain the result.

## Inputs

| Source | File/Location | Section/Scope | Why |
|--------|--------------|---------------|-----|
| Inputs | `projects/<slug>/work/sizing-01-inputs.md` | Full file | The data |
| Calculator | `python3 tools/pe.py size <inputs> --out <output>` | Command | The arithmetic; do not recompute by hand |
| Method | `knowledge/sizing/size-method.md` | "Totals" | Explain how totals arise |

Do NOT load: evidence, profiles (already copied into inputs), other projects.

## Process

1. Run `python3 tools/pe.py size projects/<slug>/work/sizing-01-inputs.md --out projects/<slug>/work/sizing-02-result.md`.
2. Report the status line and totals.
3. If INCOMPLETE, list each gap with who can close it. If the result carries a SYNTHETIC warning, say it must not be issued.
4. Flag any row that dominates a total (over half of it) so the PE checks that figure first.

## Outputs

| Artifact | Location | Format |
|----------|----------|--------|
| Sizing result | `projects/<slug>/work/sizing-02-result.md` | Generated by `pe.py size` |
